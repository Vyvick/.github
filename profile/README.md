## Engineering for infrastructure that must keep working

Vyvick Engineering is a European technology brand with Ukrainian engineering roots. The experience behind the brand began with business automation in 2001 and expanded into systems integration in 2004, followed by years of operating customer infrastructure and developing internal engineering tools.

We build practical systems for teams responsible for Windows Server environments, remote administration, security, and service continuity. Our work is guided by controlled deployment, least-privilege access, observable system state, documented recovery paths, and automation that remains understandable to the operator.

## Lira RDP Security

Lira RDP Security is Vyvick's commercial platform for centralized RDP protection and Windows Server operations. It is designed for internal IT teams, systems integrators, hosting providers, and MSPs managing multiple servers or customer environments.

Lira brings together:

- TOTP-based MFA before a protected Windows logon completes;
- detection of failed RDP authentication events and temporary source blocking through Windows Firewall;
- centralized visibility into authentication events, active blocks, agent health, Microsoft Defender, Windows Update, disk state, and RDP TLS status;
- controlled server onboarding, role-based access, audit records, and tenant-scoped separation;
- operational workflows for RDP certificates, updates, recovery, and staged deployment.

Windows and RDP passwords are validated locally on the protected Windows host. They are not sent to or stored by the Vyvick portal.

## Report a security issue

Please do not disclose suspected vulnerabilities through public GitHub issues. Use the [private security contact](https://vyvick.com/en/security.html) so the Vyvick team has a reasonable opportunity to investigate and remediate the issue before public disclosure.
